Estructura Bàsica d'un document HTML

Estructura General

  • Un document HTML es basa en una estructura jeràrquica de etiquetes que defineixen les diferents
    parts d'una pàgina.
  • Cada pàgina HTML segueix una estructura similar, començant pel <!DOCTYPE>, seguit de les
    etiquetes <html>, <head>, <body>.
